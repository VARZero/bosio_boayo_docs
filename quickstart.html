PYNQ-Z2 실행

통합 저장소를 내려받고 보드에 올린 뒤 출력과 창을 확인합니다.

가장 빠른 경로는 FullStack 저장소를 서브모듈까지 복제하고, 통합 스크립트로 보드에 배포한 다음 서비스 상태를 확인하는 것입니다.

1. 개발 소스 내려받기

git clone --recursive https://github.com/VARZero/bosio_FullStack.git
cd bosio_FullStack
python -m pip install -r requirements.txt

이미 일반 복제를 했다면 git submodule update --init --recursive를 실행합니다. 출력 코어 RTL, 센서 허브 RTL, BoAYo SDK는 각각의 구성 요소 저장소에서 내려옵니다.

2. PYNQ-Z2 배포와 실행

보드 SSH 접속 정보는 환경 변수로 전달합니다. 비밀번호나 키를 저장소에 기록하지 않습니다.

# Windows PowerShell 예시
$env:BOSIO_PYNQ_HOST = "192.168.2.99"
$env:BOSIO_PYNQ_USER = "xilinx"
$env:BOSIO_PYNQ_PASSWORD = "<보드 비밀번호>"
python scripts/bosio_stack.py deploy-start

통합 스크립트는 bitstream과 SphericalWM을 설치하고, 현재 C++ 합성기를 보드에서 빌드한 다음 BoAYo 런처·SDK·앱 예제를 배포합니다. 이후 두 systemd 서비스가 부팅 때 시작됩니다. 전체 실행 과정은 배포와 부팅에 있습니다.

3. 상태 확인

python scripts/bosio_stack.py status
# 보드에서 직접 확인할 때
systemctl is-active bosio-window-manager.service
systemctl is-active boayo-desktop.service

scene_valid=True, error=False, launcher_present=True를 확인합니다. GY-521이 연결되고 보정이 끝났다면 sensor_active=True와 증가하는 sensor_packets도 확인할 수 있습니다.

4. 창 열고 앱 실행

  1. BTN0 또는 BTN1을 누르면 유일한 BoAYo 런처 패널이 현재 시선 위치에 열립니다.
  2. 런처의 실제 실행 명령이 등록된 앱을 BTN2 시선 클릭으로 선택합니다.
  3. 앱은 별도 프로세스로 시작되고 SDK를 통해 자기 Bosio 창을 생성합니다. 런처는 앱이 시작되면 즉시 접힙니다.
  4. BTN0/BTN1로 런처를 다시 열어도 기존 앱 창은 유지됩니다. 패널 밖 클릭은 패널만 접습니다.
화면이 검정색일 때

서비스와 scene_valid를 먼저 확인합니다. 앱 시작 순간의 잠깐 검정 프레임은 허용하지만, 계속 검정이면 HDMI 연결·bitstream·장면 갱신을 확인해야 합니다. 운영 절차에 로그 명령이 있습니다.
