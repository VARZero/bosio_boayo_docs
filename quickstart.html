PYNQ-Z2 실행

통합 저장소를 내려받고 보드에 올린 뒤 출력과 창을 확인합니다.

먼저 FullStack 저장소와 하위 저장소를 함께 내려받으세요. 통합 스크립트로 PYNQ-Z2에 배포하고, Bosio·BoAYo 서비스가 시작됐는지 확인하면 됩니다.

1. 개발 소스 내려받기

git clone --recursive https://github.com/VARZero/bosio_FullStack.git
cd bosio_FullStack
python -m pip install -r requirements.txt

--recursive 없이 복제했다면 git submodule update --init --recursive를 실행하세요. 출력 코어 RTL, 센서 허브 RTL, BoAYo SDK는 각각 별도의 하위 저장소에 있습니다.

2. PYNQ-Z2 배포와 실행

보드의 SSH 접속 정보는 환경 변수로 설정합니다. 비밀번호와 개인키는 Git 저장소에 넣지 마세요.

# Windows PowerShell 예시
$env:BOSIO_PYNQ_HOST = "192.168.2.99"
$env:BOSIO_PYNQ_USER = "xilinx"
$env:BOSIO_PYNQ_PASSWORD = "<보드 비밀번호>"
python scripts/bosio_stack.py deploy-start

통합 스크립트는 비트스트림과 Bosio 창 관리자를 설치하고, C++ 합성기를 보드에서 빌드한 뒤 BoAYo 런처·SDK·앱 예제를 배포합니다. 설치된 두 서비스는 다음 부팅부터 자동으로 시작됩니다. 자세한 순서는 배포와 부팅에 있습니다.

3. 상태 확인

python scripts/bosio_stack.py status
# 보드에서 직접 확인할 때
systemctl is-active bosio-window-manager.service
systemctl is-active boayo-desktop.service

상태 출력에 scene_valid=True, error=False, launcher_present=True가 나오면 장면과 런처가 준비된 상태입니다. GY-521이 연결되고 보정이 끝났다면 sensor_active=True도 확인할 수 있습니다.

4. 창 열고 앱 실행

  1. BTN0 또는 BTN1을 눌러 런처 패널을 현재 시선 위치에 엽니다.
  2. 실행 명령이 등록된 앱을 BTN2로 선택합니다.
  3. 앱이 별도 프로세스로 시작되어 Bosio 창을 만들면 런처 패널은 닫힙니다.
  4. BTN0이나 BTN1로 패널을 다시 열어도 실행 중인 앱 창은 유지됩니다. 패널 밖을 클릭하면 패널만 닫힙니다.
화면이 계속 검정색일 때

두 서비스와 scene_valid 상태를 먼저 확인하세요. 앱 실행 순간에 검정 프레임이 잠깐 나올 수 있지만 계속 검정이면 HDMI 연결, 비트스트림, 장면 갱신을 확인해야 합니다. 배포와 부팅에 로그 확인 명령이 있습니다.
