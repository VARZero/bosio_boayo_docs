PYNQ-Z2 실행

통합 저장소를 내려받고 보드에 올린 뒤 출력과 창을 확인합니다.

현재 문서의 기준은 M=32 + 투영코어 2개 + DTF1 + HDMI 트리플 버퍼입니다. FullStack의 기존 bosio_stack.py deploy-start는 M=16 경로이므로 이 구성의 설치 명령으로 사용하지 않습니다.

1. 검증된 소스 내려받기

git clone --recursive https://github.com/VARZero/bosio_FullStack.git
cd bosio_FullStack
git checkout 8f39cdb5e255493385fa1974dffe4cd689674287
git submodule update --init --recursive
python -m pip install -r requirements.txt

명령은 새 복제본 기준입니다. 검증 당시 버전을 고정하며, 다른 버전으로 바꾸면 검증 커밋과 파일 해시를 함께 확인하세요.

2. PYNQ에서 M=32 WM 실행

보드의 FullStack 복제본에서 실행합니다. PYNQ·NumPy 등 의존성이 있는 Python 환경을 사용하고, 기존 WM/BoAYo가 하드웨어를 소유하고 있으면 먼저 서비스를 중지합니다.

# PYNQ 보드, FullStack 저장소 루트
sh components/bosio_SphericalWM/sw/native/build_pynq.sh
sudo systemctl stop boayo-desktop.service bosio-window-manager.service
sudo env XILINX_XRT=/usr /usr/local/share/pynq-venv/bin/python3 \
  components/bosio_SphericalWM/overlays/dual_projection/run.py \
  --socket-group xilinx --mouse auto --mouse-sensitivity 0.03

이 명령은 foreground WM을 실행합니다. M=32, 30Hz 갱신 제한, 배포 검증된 dual bit/HWH를 선택하며 HDMI는 720p60으로 송출합니다. Python 경로와 소켓 그룹은 해당 보드에 맞춰 조정하세요. WM 실행만으로 BoAYo가 자동 설치되지는 않습니다. 앱 실행 및 서비스 설치는 배포와 부팅을 따릅니다.

3. 상태 확인

다른 보드 터미널에서 실행합니다.

cd components/bosio_SphericalWM
/usr/local/share/pynq-venv/bin/python3 overlays/dual_projection/run.py --script check_display_health.py
/usr/local/share/pynq-venv/bin/python3 overlays/dual_projection/run.py --script display_transform.py --status

scene_valid, output error 없음, scanout.video_locked, VDMA 읽기·쓰기 오류 0과 DTF1 지원을 확인합니다. IMU 사용 시 sensor_active도 확인합니다. 서비스 active 표시만으로 장면과 소켓 준비 완료를 판단하지 않습니다.

4. 화면과 앱 조작

BoAYo 실행 후 BTN0은 Dashboard, BTN1은 앱 목록, BTN2는 클릭·드래그, BTN3은 취소입니다. 활성 창 캡션으로 닫기·이동·크기를 조절합니다. 전체 화면 방향은 회전·반전 API로 설정합니다.
