FullStack 저장소는 세 개발 저장소의 사용 버전을 하위 저장소로 고정합니다. 통합 배포 도구는 PYNQ-Z2에 비트스트림, Bosio 창 관리자, BoAYo 런처와 SDK를 순서대로 설치합니다.

복제와 배포

git clone --recursive https://github.com/VARZero/bosio_FullStack.git
cd bosio_FullStack
python -m pip install -r requirements.txt

# Windows PowerShell
$env:BOSIO_PYNQ_HOST = "192.168.2.99"
$env:BOSIO_PYNQ_USER = "xilinx"
$env:BOSIO_PYNQ_PASSWORD = "<보드 비밀번호>"
python scripts/bosio_stack.py deploy-start
python scripts/bosio_stack.py status

192.168.2.99는 현재 테스트 보드의 주소입니다. 다른 보드를 사용한다면 해당 IP 주소로 바꾸세요. 비밀번호는 환경 변수에만 설정하고 코드나 문서에 기록하지 마세요. SSH 개인키로도 접속할 수 있습니다.

부팅 자동 시작

부팅하면 bosio-window-manager.service가 먼저 창과 정이십면체 장면을 관리하고, boayo-desktop.service가 런처 패널을 Bosio 창으로 등록합니다. 두 서비스는 자동 시작됩니다. 앱은 apps.json에 등록된 명령으로 별도 프로세스에서 실행됩니다.

# 보드에서 직접 확인
systemctl is-active bosio-window-manager.service
systemctl is-active boayo-desktop.service
systemctl status bosio-window-manager.service boayo-desktop.service
journalctl -u bosio-window-manager.service -u boayo-desktop.service -n 100 --no-pager

문제가 있을 때 확인 순서

  1. SSH에 접속하고 두 서비스의 상태가 active인지 확인합니다.
  2. 통합 상태 출력에서 출력 코어 오류 여부, 장면 생성 여부, 런처 창 등록 여부를 확인합니다.
  3. 센서를 연결했다면 보정이 끝났고 자세 데이터가 들어오는지 확인합니다.
  4. HDMI 케이블, 캡처 장치와 보드의 출력 연결을 확인합니다.
  5. 런처가 없으면 BoAYo 서비스 로그를, 앱 창만 검정이면 앱 로그와 SDK 연결을 확인합니다.

위 명령은 저장소에 포함된 비트스트림을 배포합니다. OutputCore RTL이나 센서 허브 RTL을 고쳤다면 새 비트스트림을 빌드·검증한 뒤 통합 배포에 포함해야 합니다. 현재 실행 명령과 옵션은 FullStack 저장소의 README와 스크립트에서 확인하세요.
