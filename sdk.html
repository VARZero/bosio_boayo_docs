내 앱에 구면 창 붙이기

BoayoSDK로 내용을 그리고 이벤트를 받는 실전 예제를 제공합니다.

여러 Python 앱이 동일한 BoAYo 창 규칙을 쓰려면 boayo_sdk.py를 가져옵니다. SDK가 Bosio IPC 접속, 창 등록, 아래 캡션, 이벤트 분배를 맡고 앱은 내용만 그립니다.

가장 작은 실행 앱

import time
from boayo_sdk import BoayoSDK, INK

with BoayoSDK("hello") as sdk:
    window = sdk.create_window("Hello", width_deg=38, height_deg=28)

    def draw(canvas, content):
        canvas.text("HELLO", content.x + 20, content.y + 20,
                    INK, scale=3, bold=True)

    window.present(draw)
    while not window.closed:
        for event in sdk.poll_events():
            if (event.window_id == window.window_id
                    and event.type == "pointer_button" and event.pressed):
                print(f"click: ({event.x:.1f}, {event.y:.1f})", flush=True)
        time.sleep(0.05)

create_window()에 자세 좌표를 생략하면 런처가 실행 위치를 환경 변수 BOAYO_APP_AZIMUTH와 BOAYO_APP_ELEVATION으로 전달합니다. content는 캡션을 제외한 앱 내용 사각형이고 클릭 좌표 event.x/y도 그 사각형의 왼쪽 위 기준입니다. 캡션 클릭은 SDK가 자체 처리하므로 앱 내용 클릭 이벤트로 전달되지 않습니다.

이미지 전달

# image: NumPy 배열, shape=(높이, 너비, 3), RGB24
window.present_rgb(image, fit="contain")
# 필요하면 fit="stretch"

SDK가 내용을 그린 뒤 캡션을 덧그립니다. 앱은 이미 렌더링한 이미지를 그대로 전달할 수 있습니다. 보이는 픽셀의 최종 품질은 표면 크기, 창의 각도 크기, M 셀 분할도, Bosio 투영 AA에 함께 좌우됩니다. 작은 글씨에는 소스 이미지에서 충분한 획 굵기와 크게 그린 글자를 쓰는 편이 좋습니다.

현재 크기와 포커스 읽기

state = sdk.window_state(window)  # 또는 window.state
print(state.width_deg, state.height_deg)          # 구면 창의 각도 크기(°)
print(state.surface_width, state.surface_height)  # RGB24 표면 픽셀 크기
print(state.content_width, state.content_height)  # 캡션 제외 내용 크기
print(state.focused)                              # 포커스 여부

for event in sdk.poll_events():
    if event.window_id != window.window_id:
        continue
    if event.type == "resize":
        print("size", event.state.width_deg, event.state.height_deg)
        window.present(draw)  # 필요한 경우 내용 다시 그리기
    elif event.type == "focus":
        print("focus", event.focused)

SDK 0.2.0의 BoayoWindowState는 읽는 순간의 불변 스냅샷입니다. 캡션 드래그로 각도 크기가 바뀌면 resize가 한 호출에서 창당 한 번 전달됩니다. 창 밖으로 드래그가 이어져도 감지합니다. 포커스 상태는 이벤트를 처리한 뒤 갱신됩니다. 각도 크기를 조절해도 앱 RGB 표면·내용 픽셀 수는 자동으로 변하지 않습니다. 외부 Bosio IPC로 직접 바꾼 기하 정보는 SDK 창 객체와 자동 동기화되지 않습니다.

한 앱에서 여러 창

with BoayoSDK("multi-view") as sdk:
    main = sdk.create_window("Main")
    tools = sdk.create_window("Tools", azimuth=20, elevation=0,
                              width_deg=30, height_deg=22)
    main.present(draw_main)
    tools.present(draw_tools)
    while sdk.windows:
        for event in sdk.poll_events():
            if event.window_id == main.window_id:
                handle_main(event)
            elif event.window_id == tools.window_id:
                handle_tools(event)
        time.sleep(0.05)

이벤트는 앱의 SDK 연결에서 한 번만 읽고 창 ID별로 나눕니다. 앱이 정적 화면이라도 sdk.poll_events()를 계속 호출해야 닫기·이동·크기 조절에 반응합니다. 앱 목록 등록에는 apps.json의 실행 command가 필요합니다.
