앱과 UI · BoAYo 데스크톱

패널과 앱 캡션

런처 패널, 독립 앱 창, 클릭·드래그·닫기 규칙을 정리합니다.

BoAYo는 Dashboard, 앱 목록, 구면 앱 창과 캡션을 제공합니다. 현재 캡션은 활성 앱 창 바깥에 따로 표시하는 세 개의 버튼입니다.

시작과 버튼

검증된 부팅 설정은 장면과 IMU가 준비되면 Dashboard를 현재 시선에 한 번 엽니다. BTN0은 Dashboard 호출, BTN1은 앱 목록, BTN2는 클릭·드래그, BTN3은 취소입니다. 앱 목록에서 프로그램을 실행하면 목록은 숨겨지고 기존 앱 창은 유지됩니다.

캡션 위치와 크기

버튼위치고정 각도 크기동작
닫기 · 빨간 X창 오른쪽 위 바깥4° × 4°같은 버튼 안에서 눌렀다 떼면 해당 창 닫기
이동 · 점 여섯 개창 왼쪽 가운데 바깥2.88° × 10°누른 채 움직여 위치 변경
크기 · 대각 화살표창 오른쪽 아래 바깥4° × 4°누른 채 움직여 각도 크기 변경

같은 종류의 버튼은 모든 창에서 같은 크기이며, 앱 창을 확대·축소해도 버튼의 각도 크기는 유지됩니다. 이동 버튼만 세로로 길고 가로로 좁습니다. 각 버튼의 방향은 부모 창의 가로 방향에 맞춰 정렬합니다. 이는 구면상의 고정 각도 크기이며, 원근 투영된 화면에서 어느 위치든 정확히 같은 픽셀 수를 보장한다는 뜻은 아닙니다.

고정 크기 규칙은 캡션 버튼에 적용됩니다. 앱 내용은 창 크기에 따라 기존대로 확대·축소합니다. 포커스를 잃거나 최소화한 창의 캡션은 숨깁니다.

내용 갱신과 재사용

SDK 0.3.0의 SurfacePublisher는 첫 표면을 전체 전송하고 이후 실제 변경 픽셀의 최소 사각형만 전송합니다. 같은 이미지면 이미지 전송 IPC도 생략합니다. 둥근 모양은 PS coverage mask로 캐시해 HW 투영 경로를 유지합니다. 같은 위치로 최소화·복원하면 창별 투영 결과도 재사용합니다.

앱 이미지는 RGB24이며 픽셀별 알파 채널은 없습니다. 외곽 모양을 지정하는 coverage mask와 RGB 이미지의 투명도는 별개입니다. 내용 그리기와 이벤트 사용법은 앱 SDK를 참조하세요.
