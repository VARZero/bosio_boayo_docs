패널과 앱 캡션

런처 패널, 독립 앱 창, 클릭·드래그·닫기 규칙을 정리합니다.

BoAYo는 Bosio 스택 위에서 동작하는 데스크톱 UI입니다. 런처 패널과 앱 창 아래의 캡션은 다른 요소입니다. 패널은 하나이고 캡션이 없으며, 앱 창은 여러 개이고 각각 캡션을 가질 수 있습니다.

런처 패널

BTN0 또는 BTN1을 누르면 현재 시선에 패널이 새로 열립니다. 이전 패널은 제거되므로 동시에 여러 패널이 생기지 않습니다. 패널은 항상 다른 앱 창 위에 표시됩니다. 등록된 앱 목록은 JSON apps.json에서 읽으며 실제 실행 명령이 있는 항목만 표시합니다.

BTN2 또는 마우스로 앱을 선택하면 등록된 명령이 독립 프로세스로 실행되고 SDK가 현재 위치에 새 창을 만듭니다. 중간 실행 대기 화면을 오래 유지하지 않습니다. 앱 시작 뒤 패널은 접히고 기존 앱 창은 그대로 남습니다. 흰 패널 바깥의 여백이나 다른 구면 위치를 클릭하면 패널만 닫힙니다.

앱 창의 캡션

캡션은 창 아래에 그려지는 BoAYo UI 버튼 상자입니다. 기본 Bosio 상단 제목·테두리는 앱 창에 붙이지 않습니다. 창 내부의 가짜 커서 원도 표시하지 않습니다. 캡션 버튼은 창 너비에 맞춰 배치되며, 좁은 창에서도 양끝 조작부가 창 바깥으로 나가지 않도록 합니다.

영역짧은 클릭누른 채 이동
빨간 아래쪽 삼각형그 앱 창 닫기닫기 동작은 놓을 때 확정
가운데 회색 버튼창 포커스구면 위치 이동
왼쪽·오른쪽 버튼창 포커스창 각도 너비·높이 조절

BTN2를 누르고 있는 동안에는 시선 중심으로 캡션을 드래그할 수 있고, 버튼을 떼면 드래그가 끝납니다. USB 마우스 왼쪽 버튼도 지원합니다. UI 동작의 원본 구현은 BoAYo 소스와 구조 문서에서 볼 수 있습니다.

투명도

현재 앱 표면·장면 전달 형식은 RGB24입니다. 픽셀별 알파 투명도는 제공하지 않으므로 캡션은 배경을 가진 상자로 그립니다. 경계는 소프트웨어 AA로 부드럽게 만들 수 있지만 그 자체가 실제 알파 채널은 아닙니다.
